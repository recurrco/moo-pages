A read of where the team's actual JDs and workload sit today, against a 60‑day window of real operating channels — not a re-statement of intent, an assessment of what's actually happening on the floor. Ends in a proposed program map and per-person KPIs, both open for debate.

The one-line finding

The platform build and the org build were supposed to co-evolve. Neither half delivered — and that's not a coincidence. There was never an up-leveled operator role ready to use a dashboard-style tool, so tooling built for that role had nothing to land on. The org gap and the tech gap are the same gap, not two separate problems.

Automation opportunities — Manju's bench, via the Rista API

  1. Variance — same-day entry-vs-system mismatch detection instead of a mid-month mystery (the JP Nagar case, solved).
  2. GRN/dispatch — currently 100% WhatsApp screenshots. Rista already has the transaction data; this is a reporting gap, not a data gap.
  3. COGS-by-store, weekly — already computed by hand every week from data Rista already has. Close to a one-click report.
  4. Supplier scorecard — a standing view would have caught MFP's ~₹42K balance + repeat quality complaint before it sat unresolved.

Shivaraj is the natural first user of #1/#2/#4; a store-level version of #1/#3 is what Yiben/Rishabh's new store-audit scope needs.
